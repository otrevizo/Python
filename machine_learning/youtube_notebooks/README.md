# YouTube Notebooks

The Colab notebooks from the YouTube playlist
[AI and Machine Learning with Python](https://www.youtube.com/playlist?list=PLJgpRhj3_bvHVST9GVlT3_Su01bp_brLu),
exactly as built on camera. One notebook per topic.

Each notebook runs on its own. Read it on GitHub (outputs and plots included),
or click **Open in Colab** to run it yourself. No installs needed.

## Linear regression

Synthetic data: 50 points with a fixed random seed, so everyone gets the same numbers.

| Notebook | Topic | Run |
|---|---|---|
| [lr_simple_regression.ipynb](lr_simple_regression.ipynb) | Simple linear regression, y ~ var1: the model as an object, fit, coef_ and intercept_, predict, score (R²) | [Open in Colab](https://colab.research.google.com/github/otrevizo/Python/blob/main/machine_learning/youtube_notebooks/lr_simple_regression.ipynb) |
| [lr_multiple_regression.ipynb](lr_multiple_regression.ipynb) | Multiple linear regression, y ~ var1 + var2: two predictors, one model | [Open in Colab](https://colab.research.google.com/github/otrevizo/Python/blob/main/machine_learning/youtube_notebooks/lr_multiple_regression.ipynb) |

## Logistic regression

| Notebook | Topic | Run |
|---|---|---|

| [lgr_versicolor_vs_virginica.ipynb](lgr_versicolor_vs_virginica.ipynb) | Versicolor vs. virginica: two species that overlap, accuracy 0.85, the decision boundary, and the confusion matrix, by hand and with scikit-learn | [Open in Colab](https://colab.research.google.com/github/otrevizo/Python/blob/main/machine_learning/youtube_notebooks/lgr_versicolor_vs_virginica.ipynb) |
